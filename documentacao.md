Orientação do Fluxo - Criar um formulário de contato 
Dados:  nome, email, assunto, mensagemc 

Passos: 

0- Crie o repositório chamado mvc-contato e a partir do projeto completo (github.com/turma0149)
1- Crie as views públicas (landing.php, login.php) conforme desejar, pode utilizar o tema que quiser
2- Crie index.php já com a preparacao de verificar se é uma página pública
3- Crie routes.php com as páginas que um usuário logado pode ter acesso
4- Crie a view home.php com cores e ideias que desejar (é só uma página inicial do administrativo)
5- Crie a view contato.php que conterá do formulário, cuidado com id's e name's
6- Crie o contato.js da view para mascara/validar o formulário (lado cliente) 
7- Crie o controller ContatoController.php que vai receber e manipular/validar os dados
8- A medida que for precisando vá alimentando/preenchendo as pastas com helpers, validator, imagens, css entre outros
